# 循迹摆头问题 调参记录

> 记录时间：2026-10-30
> 当前板上固件：**已回退到"录视频那一版"**（内侧 380/830，外侧 320/940）

---

## 一、版本历史

| 版本 | 内侧档位 | 差速 | 外侧档位 | 差速 | 直线表现 |
|---|---|---|---|---|---|
| **V1（视频版，已回退到此）** | 380 / 830 | 450 | 320 / 940 | 620 | 摆头，弧线正常 |
| V2 | 480 / 680 | 200 | 320 / 940 | 620 | 仍摆头 |
| V3 | 510 / 660 | 150 | 380 / 900 | 520 | 仍摆头 |

### 结论

**收小差速不能解决摆头。** 差速从 450 一路降到 150（转弯半径 19cm → 59cm），摆头依旧，
说明摆头的成因不是"修正力量过大"。

而且这条路的物理下限已经撞到：R60 半圆需要的差速约 **145**，V3 的 150 已经没有余量，
继续降会让弧线切内掉线——**所以必须换思路，不能再调差速了**。

## 二、两个待实施方案（已保留，随时可上）

### 方案① 状态迟滞 —— 治「传感器阈值抖动」

**判据**：如果摆头频率很高（每秒好几次）、幅度不大，且 `g_tracking_bits` 在两三个值之间
高频跳变，就是传感器在黑线边缘反复翻转。

现在代码是"探头电平一变，1 ms 内立刻改输出"，于是黑线卡在两个内侧探头之间时，
电机会跟着 2~3 ms 的抖动来回抽。

**改法**：新状态必须连续保持 N 个控制周期才生效。

改动位置：`Core/Src/line_follow.c` 的离散分支（`LineFollow_HandleNormal` 开头）
与 `LineFollow_ResetState`。

```c
/* control_config.h 增加 */
#define LINE_FOLLOW_PATTERN_HOLD_CYCLES   (8U)   /* 8 个周期 ≈ 8 ms；抖就加大到 15~20 */

/* line_follow.c 文件级静态变量 */
static uint8_t s_active_bits;      /* 当前生效的位图 */
static uint8_t s_pending_bits;     /* 待确认的位图 */
static uint8_t s_pending_cycles;   /* 已连续保持的周期数 */

/* LineFollow_ResetState() 里清零这三个 */

/* LineFollow_HandleNormal() 离散分支开头替换取位图的那一行 */
uint8_t bits = result->control.track.black_bits;
if (bits == s_pending_bits) {
    if (s_pending_cycles < 255U) { ++s_pending_cycles; }
} else {
    s_pending_bits   = bits;
    s_pending_cycles = 0U;
}
if (s_pending_cycles >= LINE_FOLLOW_PATTERN_HOLD_CYCLES) {
    s_active_bits = bits;          /* 确认生效 */
} else {
    bits = s_active_bits;          /* 沿用旧状态，忽略这次跳变 */
}
```

**代价**：状态切换延迟 8 ms。对 1 ms 控制周期来说可以接受；如果发现入弯变迟钝，
把 `LINE_FOLLOW_PATTERN_HOLD_CYCLES` 降到 4~5。

---

### 方案② 降基速 —— 治「机械响应滞后」

**判据**：如果摆头频率低（1~2 Hz）、幅度大、像画龙，就是电机+车身的机械响应
慢于控制周期，改多少差速都没用——车"听不进去"。

**改法**：直行基准 580 → 520（三个值必须一起改，否则参数校验判非法直接停车）：

```c
#define CONTROL_BASE_SPEED_DEFAULT             (520.0f)   /* 580 → 520 */
#define LINE_FOLLOW_CURVE_SPEED_DEFAULT        (500.0f)   /* 560 → 500，必须 ≤ base */
#define LINE_FOLLOW_SHARP_CURVE_SPEED_DEFAULT  (480.0f)   /* 540 → 480，必须 ≤ curve */
```

**副作用**：整体变慢，单圈耗时增加约 10%。

## 三、下一步怎么走

1. 先按 V1（当前板上版本）跑一次，确认现象与视频一致；
2. 判断摆头频率：
   - 每秒好几次、幅度小 → **上方案①**（改代码）
   - 每秒 1~2 次、幅度大 → **上方案②**（改参数，2 分钟）
3. 两者可以叠加：先用②把速度降下来看幅度变化，不够再加①。

## 四、怎么量摆头频率

把车架起来（轮子悬空），手拿一张黑纸在四个探头下方慢慢横向移动：

- 指示灯（或 `g_tracking_bits`）在某个位置**来回闪** → 阈值抖动 → 方案①
- 指示灯**过渡干净**（压上就亮、离开就灭）→ 传感器没问题 → 方案②

## 五、与「直角不识别」的关系

直角问题是另一条线：线在视野里 90° 折弯，四路同时读空（全白）或同时读黑（全黑），
而代码里全白走"直行 25 ms → 差速搜索"、全黑直接判故障停车。
这部分要改状态机，等摆头解决后再动。
