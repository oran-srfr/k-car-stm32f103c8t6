# 2026-11-05 固件版本

本版本同步桌面 8 目录中已验证的源码和最新障碍停车恢复修复。

## 行为

- 直角目标 95°，转向命令 500；转向阶段持续计算角速度并提前刹车，处理 yaw 跨越 ±180°。
- 直角后 3500 ms 缓和窗口：仅两内探头同时压线时限制总差速，前 3000 ms 上限 80，最后 500 ms 渐进放宽；暂停后保留剩余窗口。
- 控制计时、FF、滤波及斜率限制使用实际 elapsed_ms，运行时暂停阻塞的屏幕刷新。
- 障碍近距离先停车；连续三个独立近距离回波才报警，同次停车仅报警一次；连续三个 >100 mm 有效回波才恢复，失效回波不授权恢复。
- 修复停车时清除最后见线方向的错误：保留最后有效偏差/方向，清除 FF 等控制累积。解除障碍仍离线时按最后方向温和找线，最多 500 ms；默认逻辑轮命令 450/570 或 570/450，找回即恢复，超时停车。冷启动无历史仍不允许盲搜。
- 补齐全黑穿越配置（450、150 ms），并正确清零连续计时；复位完赛标志，修复黑匣子冻结计时与异常处理输出关闭。

## 范围与限制

电机命令是 PWM 驱动单位，不是实测 RPM。软件恢复修复不能保证解决电机启动造成的供电压降、指示灯变暗或反复复位，需要实车测量。
B/C 点事件尚未接入，K230 识别、侧方/倒车执行及实体停止按钮仍为占位；本次提交不包含其他工作区中的停车/视觉开发改动。

运行测试：Windows 使用 tests/run_tests.ps1（需主机 GCC）；其他平台使用 tests/run_tests.sh。完整固件通过 CMake 和随仓库提供的 ARM 工具链配置构建。
